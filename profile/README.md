## What we build

[Cirth](https://github.com/cirthcss/cirth) is a small CSS framework centered
on semantic HTML, accessible defaults, native browser behavior, and a public
custom-property surface. It ships default, classless, scoped, and preset
builds without requiring JavaScript.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cirthcss/cirth/dist/cirth.min.css">

<main class="container">
  <article>
    <h1>Ordinary HTML, useful defaults</h1>
    <button type="button">Continue</button>
  </article>
</main>
```

## Project principles

- **Semantic first:** style native elements before inventing abstractions.
- **Accessible by default:** treat keyboard use, contrast, motion, and robust
  markup as product requirements.
- **CSS first:** use custom properties and modern CSS instead of a runtime.
- **Small public surface:** keep APIs explicit, documented, and stable.
- **Production minded:** back behavior with CI, visual regression, accessibility
  checks, package validation, and documented release workflows.
